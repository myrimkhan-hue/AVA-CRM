Инструкции для сотрудников

Короткая памятка по работе в CRM — отдельно для каждой роли. Выберите свою роль ниже. Если у вас несколько ролей (например, «Менеджер + Логист»), прочитайте обе инструкции — в системе вы увидите объединённый набор возможностей.

Менеджер

Менеджер

Сделки, перевозки, счета клиентам, договоры и акты, мотивация.

 Логист

Логист

Ведение перевозок по статусам, данные для заявок, заявки на оплату перевозчикам.

 Финансист

Финансист

Счета, оплаты, заявки на оплату, операционные расходы, отчёты и настройки валют.

 Руководитель

Руководитель / Руководитель отдела

Обзор дашборда, согласование заявок на оплату, контроль договоров и мотивации.

 Администратор

Администратор

Пользователи и доступы, справочники, шаблоны документов, настройки компании.
Общее для всех ролей. Вход — по рабочему email и паролю, которые выдаёт администратор (см. инструкцию «Администратор»). Сессия автоматически завершается после 12 часов бездействия. Если забыли пароль — обратитесь к администратору, он сбросит его через раздел «Пользователи».
